# П2 · Матрицата

Попълваш `partidi/<партида>/matrica.json`. Празният скелет вече е там (`./mashina partida нова`).

## Правила
1. **Победителите първо:** ad set **A** е ъгълът на победителя от акаунта (ако има). B и C са нови ъгли от брифа.
2. **Един ad set = един ъгъл.** Така в отчета виждаш кой ъгъл продава.
3. **В ad set-а 4-те банера сменят по една ос:** хук, оформление, снимка, доказателство. Не всички наведнъж.
4. Ad set `ime`: `PF · <код> · <ъгъл> · <ситуация>` (напр. `PF · A · болка · кръст след седене`).

## Полета на банер
| Поле | Какво | Пример |
|---|---|---|
| `oformlenie` | `snimka` (оферта) · `bolka` · `dokazatelstvo` · `mehanizam` · `sravnenie` | `bolka` |
| `snimka` | твоя снимка в `partidi/<п>/snimki/` (за предпочитане) | `snimki/rumen-kraka.jpg` |
| `prompt_snimka` | само ако няма твоя снимка → skill **banner-prompt** | |

| `akcent` | 1–3 думи от заглавието, в оранжево | `8 часа седене` |
| `podzaglavie` | по желание, 1 ред | `Преглед и план в Пловдив` |
| `hapche` | по подразбиране „Запиши час“ | |
| `stapki` | само за `mehanizam`: до 3 кратки стъпки | |
| `mit` / `fakt` | само за `sravnenie` | |

## Полета на видео (виж skill **video**)
`huk` (първите 2–3 сек) · `tyalo` · `priziv` · `glas_tekst` (целият текст за озвучаване, 20–35 сек) · `kadri` (3–6 сцени: `{"fail": "snimki/x.mp4", "sek": 3}` или `{"ai_prompt": "...", "sek": 8}`).

## Хуковете
Използвай `resursi/100-huka.md`. Формула: **ситуация + изненада + обещание**, до 8 думи. Тест: би ли го казал на кафе?

## Проверката преди парите
`./mashina smetka` проверява всичко „на хартия“ (буква по буква, цени, здравни правила, дължини) и показва цената. Оправяш всички ✗. Тогава **Стоп А**.
