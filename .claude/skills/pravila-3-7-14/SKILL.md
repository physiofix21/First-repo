# Правилата 3 · 7 · 14

**Таванът (T)** = колко най-много плащаш за едно съобщение, без да губиш (`./mashina ikonomika`):
`приход от нов пациент за 60 дни × дял за реклама × % съобщение→час × % дошли`

## Винаги
- **0 съобщения и разход ≥ 2T → СПРИ.**

## Ден 0–2 · не пипаш
Нищо. Meta учи. Изключение: горното правило.

## Ден 3 · първи поглед
| Условие | Решение |
|---|---|
| CTR < 0.6% при ≥ 1500 показвания | **СПРИ** — хукът не спира пръста |
| € на съобщение > 2T и разход ≥ 1.5T | **СПРИ** |
| иначе | **ОСТАВИ** — събира данни |
Не пипаш бюджета на ad set-а. Не добавяш реклами.

## Ден 7 · решението
| Условие | Решение |
|---|---|
| € на съобщение > 1.5T | **СПРИ** |
| ≥ 3 съобщения и € на съобщение ≤ 0.8T | **УМНОЖИ** (≥10 съобщения = сигурно) |
| € на съобщение ≤ T | **ОСТАВИ** |
| между T и 1.5T | **ОСТАВИ**, гледай в ден 14 |

## Ден 14 · умората и следващата партида
| Условие | Решение |
|---|---|
| честота ≥ 3 и € на съобщение > T | **СПРИ** — умора |
| победител | нов ad set „· вълна 2“ (skill **umnozhavane**) |
| няма победител | нова партида с нови ъгли от брифа; губещите ъгли не се повтарят |

## Ad set ниво
Ако всички реклами в ad set са СПРИ → спри ad set-а: ъгълът не работи. Запиши го в брифа като „не работи“ за следващия път.

Логиката е в `paket/mashina/otchet.py → reshi()`. Ако човекът иска други прагове, промени ги там и в този файл заедно и пусни тестовете.
