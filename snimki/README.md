# Снимките на PhysioFix

Сложи тук истински снимки и клипове от кабинета (терапевт в работа, ръце, маса, уреди, екипът, входът на Севастопол 19). Машината ги предпочита пред AI.

- Без пациенти, които не са дали писмено съгласие. Без преди/след.
- Добре: вертикални клипове 9:16 по 3–10 сек, снимки ≥ 1500 px.
- За партида копирай нужните в `partidi/<партида>/snimki/`.

Тази папка не се качва в git (тежки файлове, лични данни).
